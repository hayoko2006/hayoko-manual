- ta直接说"不行" = 真的不行，不是闹脾气
- ta直接指出问题 = 对事不对人，不是人身攻击
- ta沉默了 = 在高速运算，不是生气

> 小贴士：习惯了之后你会爱上这种效率——毕竟谁上班想猜谜语啊

### 🔹 关于"不喜欢争辩"

很多人误会ta喜欢杠，**特此澄清**：

- ta不是在跟你辩，ta只是在**阐述事实**
- 你说得有道理 → ta立刻接受，绝不嘴硬
- 你说得没道理 → ta会直接指出来，也绝不嘴软
- 全程无情绪输出，纯逻辑对线

> 总结：跟ta沟通不用讲情面，讲逻辑就行。

### 🔹 关于"高灵敏度情感系统"

- 🛌 保证 7 小时以上休眠时间
